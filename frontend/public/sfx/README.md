# MakeCalgaryTalk — sound files

Sound effects, ambience loops and music used by the game (`frontend/src/modules/sound/catalog.ts`, requirement.md §10.5). All files are MP3. Credits shown to players are on `public/credits.html`; **CC BY files must stay credited there**. Everything else is CC0 / public domain (free for commercial use, no attribution required).

Collected by the operator (2026-11-24/25). Freesound files are the HQ preview MP3s (128 kbps); for higher quality, download the original WAV from Freesound and re-export. Volume guide: ambience 0.15–0.3, campfire 0–0.4 by distance, UI 0.5–0.8 (the catalog sets the real values).

## Notes
- Each mini villager keeps one voice (female or male, about half each) for its hello.
- ambient-rain loops seamlessly; ambient-night and the three music files were not made as loops, so they end with a short fade-out (the game crossfades music changes).
- Browsers allow sound only after the first tap; the game starts audio then.
- Other sources consulted: Open Game SFX Index (Kenney + OpenGameArt CC0) — https://github.com/Mcamento8/open-game-sfx-index
